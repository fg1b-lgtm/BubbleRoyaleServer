# practice — 지우고 다시 쓰기

CLAUDE.md A구역 **4단계 학습 루프의 3단계** 전용 폴더다.

```
1단계  보여준다        →  완성 코드 + 줄마다 왜 그렇게 쓰는지
2단계  이해를 점검한다  →  줄을 지목해 묻고, 각 블록에 내 말로 주석을 단다
3단계  지우고 다시 쓴다 →  ★ 여기가 이 폴더다
4단계  구술 테스트      →  코드 안 보고 "왜 그렇게 했나"에 답한다
```

## 하는 법

1. 진짜 파일(`Server/src/main.cpp` 등)에 **내 말로 된 한글 주석**을 먼저 달아둔다.
2. 그 **주석만** 이 폴더의 빈 파일에 옮겨 적는다. 코드는 옮기지 않는다.
3. 주석만 보고 **처음부터 직접 친다.** 원본은 열지 않는다.
4. 컴파일한다. **에러가 나는 건 정상이다. 그 에러 목록이 아직 안 익은 곳의 지도다.**
5. 막힌 줄만 원본을 보고 1단계로 되돌린다. 전체를 다시 보지 않는다.

## 컴파일 (Windows)

```bat
build.bat d11-echo\server.cpp
```

성공하면 `practice\bin\server.exe` 가 나온다. 그냥 실행해보면 된다.

`ws2_32.lib` 링크, `/W4`, `/std:c++17`, `/utf-8` 은 스크립트가 알아서 붙인다.
Visual Studio 를 열 필요 없다.

> 실행할 때 포트 9000이 이미 물려 있으면 `bind failed: 10048` 이 난다.
> 진짜 서버(`bin\x64\Debug\Server.exe`)를 끄고 다시 하거나,
> 연습 파일의 포트 상수만 9001 로 바꿔라.

## 컴파일 (맥북)

화·수·금 저녁은 학교에서 맥북으로 한다. 맥에서는 `build.sh` 를 쓴다.

```sh
cd practice
chmod +x build.sh          # 처음 한 번만
./build.sh 2026-08-31-jobqueue/jobqueue.cpp
./bin/jobqueue
```

컴파일러가 없다고 하면 `xcode-select --install` 을 먼저 한다.

**맥에서 되는 것과 안 되는 것**

| 폴더 | 맥 | 왜 |
|---|---|---|
| `2026-08-31-jobqueue/` | ⭕ | `win_compat.h` 가 Windows 이름을 대신 채워준다 |
| 수신 버퍼 / 송신 버퍼 | ⭕ | 순수 C++ 다. Windows API 를 안 쓴다 |
| `d9-session/` `d10-iocp/` | ❌ | IOCP 는 맥에 없는 물건이다. 흉내낼 수 없다 |
| `d10-select/` `d11-echo/` | ❌ | 소켓 이름이 다르다. 고쳐 쓰면 연습이 안 된다 |

**소켓이 들어가는 연습은 집에서 한다.** 학교에서는 자료구조와 락 쪽만 한다.

`win_compat.h` 는 `SRWLOCK`, `InterlockedIncrement`, `CreateThread` 같은 이름을
맥 쪽 물건으로 바꿔 끼우는 껍데기다. **연습 코드를 맥용으로 고쳐 쓰지 않기 위해서 있다.**
면접에서 묻는 건 Windows 이름이고, 손이 기억해야 하는 것도 그 이름이다.

> 이 껍데기는 Windows 에서만 확인했다. **맥에서 처음 돌리는 건 화요일 저녁이 된다.**
> 그때 컴파일 에러가 나면 그건 연습 실패가 아니라 껍데기 문제다. 에러를 그대로 들고 와라.
